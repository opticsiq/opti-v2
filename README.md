# Opti - منصة النظارات الطبية

## نظرة عامة
Opti هي منصة متكاملة لإدارة بيع النظارات الطبية والعدسات اللاصقة، مصممة للعملاء والمدراء مع واجهة مستخدم حديثة وسهلة الاستخدام.

### للمدراء:

- ✅ إدارة المستخدمين والصلاحيات
- ✅ دعم العملاء والدردشة

## التقنيات المستخدمة

### Frontend:
- **React 18** مع TypeScript
- **Vite** كأداة بناء
- **Tailwind CSS** للتصميم
- **Shadcn/ui** لمكونات الواجهة
- **React Router** للتنقل
- **React Query** لإدارة الحالة

### Backend:
- **Node.js** مع Express
- **SQLite** لقاعدة البيانات
- **JWT** للمصادقة
- **bcryptjs** لتشفير كلمات المرور
- **Multer** لرفع الملفات

## التثبيت والتشغيل

### المتطلبات الأساسية:
- Node.js (الإصدار 18 أو أحدث)
- npm أو yarn

### خطوات التثبيت:

1. **استنساخ المشروع:**
```bash
git clone <repository-url>
cd opti
```

2. **تثبيت تبعيات Frontend:**
```bash
npm install
```

3. **تثبيت تبعيات Backend:**
```bash
cd server
npm install
```

4. **إعداد قاعدة البيانات:**
```bash
cd server
node setup-db.js
```

5. **تشغيل الخادم:**
```bash
cd server
npm run dev
```

6. **تشغيل التطبيق الأمامي:**
```bash
# في مجلد جديد
npm run dev
```
