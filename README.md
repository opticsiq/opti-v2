# Opti - منصة النظارات الطبية

## نظرة عامة
Opti هي منصة متكاملة لإدارة بيع النظارات الطبية والعدسات اللاصقة، مصممة للعملاء والمدراء مع واجهة مستخدم حديثة وسهلة الاستخدام.

## التقنيات المستخدمة

### Frontend:
- **React 18** مع TypeScript
- **Vite** كأداة بناء
- **Tailwind CSS** للتصميم
- **Shadcn/ui** لمكونات الواجهة
- **React Router** للتنقل
- **React Query** لإدارة الحالة
- **Sonner** للإشعارات

### Backend:
- **Node.js** مع Express
- **SQLite** لقاعدة البيانات
- **JWT** للمصادقة
- **bcryptjs** لتشفير كلمات المرور

## التثبيت والتشغيل

### المتطلبات الأساسية:
- Node.js (الإصدار 18 أو أحدث)
- npm

### خطوات التثبيت:

1. **استنساخ المشروع:**
```bash
git clone https://github.com/opticsiq/opti-v2
cd opti-v2
```

2. **تثبيت تبعيات Frontend:**
```bash
npm install
```

3. **تثبيت تبعيات Backend:**
```bash
cd server
npm install
cd ..
```

4. **تشغيل الخادم:**
```bash
cd server
npm run dev
# أو
node index.js
```

5. **تشغيل التطبيق الأمامي (في terminal منفصل):**
```bash
npm run dev
```

## API Endpoints

### Authentication:
- `POST /api/login` - تسجيل الدخول
- `GET /api/profile` - الملف الشخصي

### Data:
- `GET /api/orders` - الطلبات
- `GET /api/products` - المنتجات
- `GET /api/stats` - الإحصائيات (للمدراء فقط)

### Health:
- `GET /api/health` - فحص حالة الخادم

## المسارات الرئيسية

### مسارات العملاء:
- `/` - الصفحة الرئيسية
- `/login` - تسجيل دخول العملاء
- `/orders` - الطلبات
- `/earnings` - الأرباح
- `/profile` - الملف الشخصي
- `/new-order` - طلب جديد

### مسارات المدراء:
- `/admin/login` - تسجيل دخول المدير
- `/admin/dashboard` - لوحة التحكم
